04 / What can be delegated?

Capacidade de executar.
Legitimidade para decidir.

O sistema deve ocupar esta função?

Pode verificar a própria execução?
Pode controlar o registro usado para prová-la?
Pode julgar conflitos dos quais participa?

Arquitetura de verificação

Separação entre execução, prova e adjudicação.
Independência de funções com conflito de interesse.
Proveniência, reconstrução temporal e accountability.

Pesquisa: Impossible Delegation · Universal Verification Principle · The Blind Algorithm · Algorithmic Verifiability
